## US-M2-001（P0）数据源与任务触发

| 字段 | 内容 |
|------|------|
| **编号** | US-M2-001 |
| **故事** | 作为数据工程，我希望查看已配置数据源并触发一次同步，以便把资讯灌入投研消息池。 |
| **AC** | 1) `GET /ingest/sources` 返回 `items` 含 `sourceId`、`enabled`、`lastJobStatus`；2) `POST /ingest/jobs` 返回 `jobId` 且初始 `status` 为 `queued` 或 `running`；3) `GET /ingest/jobs/{jobId}` 可拉取终态与 `stats`；4) 成功路径 `stats.publishedToM1` 或缓冲表有计数（与实现一致并在 `14` 说明）。 |
| **REQ** | REQ-M2-001 |

## US-M2-002（P0）失败可观测

| 字段 | 内容 |
|------|------|
| **编号** | US-M2-002 |
| **故事** | 作为数据工程，我希望同步失败时能看到错误摘要与 trace，以便排障。 |
| **AC** | 1) `failed` 任务含 `errorSummary` 或 `errors[]`；2) 错误响应体含 `traceId`；3) 日志带 `module=M2` 与 `jobId`。 |
| **REQ** | REQ-M2-002 |

## US-M2-003（P1）幂等与并发

| 字段 | 内容 |
|------|------|
| **编号** | US-M2-003 |
| **故事** | 作为系统，我希望同源并发任务受控，以便保护上游。 |
| **AC** | 同源第二任务在策略为禁止并行时返回 **409** `M2_JOB_ALREADY_RUNNING`（或等价）。 |
| **REQ** | REQ-M2-003 |
