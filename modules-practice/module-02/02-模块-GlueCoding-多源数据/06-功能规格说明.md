# 06 — 功能规格说明

| 属性 | 内容 |
|------|------|
| **模块编号** | M2 |
| **模块名称** | Glue Coding · 多源数据（Wind / 新浪等） |
| **文档包版本** | v1.2 |
| **技术栈** | 前端 React · 后端 Flask · 代码 GitHub |
| **开发方式** | CoPaw + 本模块 Spec |
| **模块侧重** | 多源行情与资讯的采集、清洗、调度与可观测；强调数据管道与失败降级。 |

---

## 1. 边界与集成（可先独立）

- **P0**：数据源配置 + 触发同步 + 任务列表/详情 + Mock Provider 跑通；写入 **同库** `research_messages` 或与 `ingest_feed_items` 缓冲（`10` §2.3）。  
- **不阻塞 M1**：M1 可用种子数据并行开发；联通后打开「发布到 M1」开关。  
- **M3**：清洗文本导出 P1。

## 2. 前端路由（React）

| 路由 | 职责 |
|------|------|
| `/ingest/sources` | 数据源卡片：状态、`lastSuccessAt`、启用开关（需权限） |
| `/ingest/jobs` | 任务历史表 + 筛选 `sourceId`/`status` |
| `/ingest/jobs/:jobId` | 详情：`stats`、`errors` 展开 |

页脚免责声明；运维页 **不** 展示 `secret_ref` 明文。

## 3. 状态与交互

- 触发任务后 **轮询** 或 **SSE**（P1）更新 `job.status`。  
- `partial`：展示成功条数 + 失败抽样，引导看日志/traceId。  
- 与 `05` AC 对齐。

## 4. 后端（Flask）

- Blueprint：`data_pipeline_bp` 或 `ingest_bp`，前缀 `/api/v1/ingest`。  
- 长任务：**异步 worker**（线程/队列/FC）；`POST /jobs` 立即 `queued` 返回。  
- 与 `09` 错误码一致。

## 5. 兄弟模块

见 `09` §4、`10` §5。
