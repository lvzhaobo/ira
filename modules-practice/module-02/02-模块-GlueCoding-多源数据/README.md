## 模块目标

多源行情与资讯的采集、清洗、调度与可观测；强调数据管道与失败降级。

## 集成说明

向 M1 提供统一消息/资讯写入接口或主题；M3 可选用清洗后的文本片段。

## CoPaw 与本模块

- **推荐**：**Cron** 或 **Skill** 触发同步任务 → HTTP 调本模块 BFF（写入/重跑与 `09` 对齐）；**MCP** 封装外部数据源（合规 Provider），BFF 只认结构化结果。  
- **不宜**：用 Agent 循环替代 **幂等、可审计的批处理作业** 核心逻辑；调度状态机仍以应用代码 + DB 为准。  
- **原则**：[`00` §7](../00-全项目-企业研发规范-Mock.md)。

## 阿里云（适当使用）

建议日志 SLS；大批量落地 OSS + 外表或同步至 RDS；调度可配合 FC 触发器（可选）。
