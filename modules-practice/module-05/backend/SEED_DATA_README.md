# 数据库种子数据脚本使用说明

## 功能说明

`seed_data.py` 脚本用于向数据库添加测试数据，包括：
- 基金经理数据（8位）
- 基金数据（20只，包含股票型、混合型、债券型、指数型）
- 基金净值数据（每只基金最近30天，共600条）

## 使用方法

### 1. 确保数据库已初始化

```bash
cd backend
flask init-db
```

### 2. 运行种子数据脚本

```bash
cd backend
python seed_data.py
```

### 3. 验证数据

脚本运行完成后会显示统计信息：
- 基金经理数量
- 基金数量
- 净值记录数量

## 注意事项

1. 脚本会检查数据是否已存在，避免重复添加
2. 净值数据为模拟生成的随机数据，用于测试展示
3. 基金规模单位为元（脚本中输入的数值单位为亿元，会自动转换）
4. 所有基金状态默认为 active（运作中）

## 重新生成数据

如需重新生成数据，可以：
1. 删除数据库文件（app.db）
2. 重新初始化数据库：`flask init-db`
3. 运行种子脚本：`python seed_data.py`
