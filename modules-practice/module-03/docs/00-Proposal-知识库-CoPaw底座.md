# Proposal：机构投研知识库与研报问答（CoPaw 作为 Workshop 底座）

> **文档类型**：Proposal（立项 / 范围评审稿）  
> **版本**：v0.1  
> **日期**：2026-04-03  
> **适用范围**：单环节 Workshop——本目录内 **`00-Proposal` → `01-Spec` → `02-TC`** 三段式自洽；不依赖本目录外的代码或物料。

---

## 0. 流程位置（与 Spec、TC 的关系）

| 阶段 | 文档 | 作用 |
|------|------|------|
| 1 | **本文 Proposal** | 说清楚「做不做、做什么、不做什么」；**先评审、后定稿** |
| 2 | **`01-Spec`** | 冻结 **可开发契约**（API、行为、CoPaw 映射）；**须在 Proposal 通过后再定稿/冻结** |
| 3 | **`02-验收清单与TC`** | 验收与测试用例；**对齐已冻结的 Spec 版本** |

**门禁**：**Proposal 评审通过** 后，方可将对应版本的 **Spec 标为冻结** 并进入按契约开发与验收。（评审形式：会议纪要、标签、负责人签字等，由组织自定。）

---

## 1. 背景与问题

投研业务依赖 **内部允许的研报与材料**。分析师需要：

1. 将材料 **入库** 并留下可审计的元数据；  
2. 基于 **已入库内容** 提问，得到 **有依据** 的回答（可展示引用）；  
3. 全流程 **可追溯**（单次操作可对应到一次「问答/入库」记录）。

Workshop 约定：**CoPaw 作为集成与编排的基础底座**（Agent / Workflow / Skill / 可选 Channel·Cron）。**对外契约与业务行为以评审通过后冻结的 `01-Spec` 为准**，不绑定某一具体商业产品版本号。

---

## 2. 目标（本环节要达成什么）

| 编号 | 目标 | 说明 |
|------|------|------|
| G-01 | **可演示的端到端链路** | 材料进入知识域 → 可被问答引用 → 用户可见「答案 + 引用列表」 |
| G-02 | **CoPaw 可参与编排** | 至少一处：**Skill 调 HTTP** 或 **Workflow 串联「入库子步骤 / 问答子步骤」**（详见 `01-Spec`） |
| G-03 | **契约稳定** | 请求/响应主字段在 **冻结后的 Spec** 中锁定；迭代以 **可选扩展字段** 或 **Spec 升版** 完成 |
| G-04 | **合规占位** | 无可靠材料时 **拒答或空证据**，行为在 Spec 与 `02-TC` 中可测 |

---

## 3. 用户与场景（摘要）

| 角色 | 典型场景 |
|------|----------|
| 分析师 | 上传 PDF/文本类研报 → 在对话中针对材料提问 → 查看引用来源 |
| 管理员（可选） | 查看索引/入库状态（演示级即可） |

---

## 4. 范围（In Scope）

- 材料 **上传与元数据记录**（文件名、入库时间、文档 ID 等，字段以 **`01-Spec` 为准**）。  
- **知识条目列表**（只读查询，供前端或 CoPaw 侧展示）。  
- **单轮或多轮问答**（当前 Spec 以 **单轮 + session 占位** 为主；多轮可为 P1）。  
- **引用结构**：每条引用含文档标识、可选页码/片段定位、可选相关度。  
- **trace_id**：每次问答（及可选的入库操作）可关联同一追溯 ID 体系。  
- **CoPaw**：至少定义 **一个 Skill** 或 **一条 Workflow** 与「问答或入库」路径对接（逻辑设计在 `01-Spec`，实现可后置）。

---

## 5. 非目标（Out of Scope，本版明确不做）

- 生产级 **多租户隔离、细粒度 ACL**（可文字预留字段，不实现完整权限引擎）。  
- 全量 **向量检索精度调优**、亿级文档性能（允许 Mock 或前 N 条策略，须在 Spec 声明）。  
- 与 **具体券商核心系统** 的实时对接。  
- 本目录 **不要求** 附带可运行仓库、CI、部署脚本——本环节交付 **Proposal + Spec + TC** 文档闭环。

---

## 6. 与 CoPaw 的分工原则（Proposal 层）

| 层级 | 职责 |
|------|------|
| **CoPaw** | 对话入口、工具调用、工作流编排、（可选）定时任务触发；**不**单独作为业务契约的唯一真源。 |
| **业务服务（BFF）** | 对外 REST、入库落库、组装 `evidence_refs`、与合规扫描接口对接（若 Spec 含）。 |
| **细化** | 接口路径与字段以 **`01-Spec` 冻结版** 为准。 |

---

## 7. 优先级（与 `01-Spec` 章节对应）

| 优先级 | 内容 |
|--------|------|
| **P0** | 入库元数据 + 列表查询 + 问答返回 `answer` + `evidence_refs` + `trace_id` |
| **P1** | 索引状态字段、解析进度、session 多轮 |
| **P2** | 真实向量检索、混合检索、流式输出 |
