## 版本命名规范

**Spec 文档:** `v{major}.{minor}`
- major: 破坏性变更(字段删除、路径变更)
- minor: 新增可选字段、新增 API

**规范文档:** `v{major}.{minor}`
- major: 规范重大调整
- minor: 补充说明、示例更新

**Task 文档:** `v{major}`
- 每次重大更新递增

**OpenAPI:** `{major}.{minor}.{patch}`
- 遵循 Semantic Versioning

## 变更记录维护规则

1. **每次 Spec 变更** 必须记录到 Changelog
2. **规范文档更新** 必须更新版本号
3. **破坏性变更** 必须标注并说明迁移方案
4. **Task 更新** 记录主要变更
5. **每月总结** 一次变更历史
