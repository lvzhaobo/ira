⚡ 关键技术: 熔断降级与Saga模式
  • 熔断器(Circuit Breaker)： 连续失败5次后打开熔断，直接返回降级数据，避免级联故障
  • 降级策略： SAP不可用时，返回缓存数据；缓存过期则返回"数据暂时不可用"提示
  • Saga事务： 长事务拆分为本地事务，失败时执行补偿操作（如取消订单释放库存）
  • 日志追踪： 使用OpenTelemetry实现全链路追踪，tx_id贯穿所有服务调用
