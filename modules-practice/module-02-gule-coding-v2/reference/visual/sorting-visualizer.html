冒泡排序 (Bubble Sort)

通过重复遍历数组，比较相邻元素并交换位置，使较大的元素逐渐"冒泡"到数组末尾。简单直观但效率较低。

时间复杂度(最优): O(n)
时间复杂度(平均): O(n²)
时间复杂度(最差): O(n²)
空间复杂度: O(1)
