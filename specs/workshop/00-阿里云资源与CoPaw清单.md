# 阿里云资源与 CoPaw 清单（Mock）

> 与 [`00-全项目-企业研发规范-Mock.md`](./00-全项目-企业研发规范-Mock.md) **§6** 配套；Workshop 用 **Mock** 命名空间，生产以机构规范为准。

| 资源类型 | 典型用途（投研助手 Workshop） | 与模块关系 |
|----------|------------------------------|------------|
| **ECS / 计算** | 部署 Flask BFF、Nginx、Demo | `ira/`、`demo/`、各 `module-*` 生产形态参考 |
| **RDS / PostgreSQL** | 消息、任务、用户、审计表 | M1 / M2 / M4 / M5 的 `10-数据模型` |
| **OSS** | 大文件、快照、批量落地 | M2 管道、M3 上传（若对接） |
| **SLS / 日志** | 结构化日志、检索与告警 | M2 可观测、M4 发送审计 |
| **API 网关 / SLB** | 公网入口、限流 | 与 `09` 对外路径一致 |
| **大模型 Key（如百炼等）** | LLM 调用（脱敏后） | M3 / M5；**密钥不入库、不写 Spec 正文** |

## CoPaw 运行依赖（概念）

| 项 | 说明 |
|----|------|
| **控制台** | 本地或内网部署 CoPaw Console（参见仓库 `copaw/`） |
| **工作目录 / 密钥卷** | 与官方文档一致；Workshop 用 `.env` 本地注入 |
| **出站网络** | 访问 BFF 的 `IRA_*` / `BFF_BASE_URL` 等环境变量 |

## 与五模块规格包

- 各模块 **`08-系统架构`**、**`07-非功能`** 中涉及云资源的句子，应与本表 **不冲突**；冲突时以 **机构采购与等保** 为准。
