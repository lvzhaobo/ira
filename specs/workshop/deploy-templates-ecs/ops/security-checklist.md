# ECS 安全检查清单（最小版）

## 安全组

- [ ] 仅开放 `80/443` 到公网。
- [ ] `22` 仅允许运维固定 IP 段访问。
- [ ] 后端端口（如 `5000`）不对公网放行，仅本机回环或内网。

## 主机与账号

- [ ] 禁止 root 直登；使用普通账号 + sudo。
- [ ] 开启 SSH key 登录，关闭密码登录（或至少限制强密码 + fail2ban）。
- [ ] 定期更新系统补丁与 OpenSSL/Nginx。

## 应用与密钥

- [ ] `.env` 不入库，不出现在日志。
- [ ] `DASHSCOPE_API_KEY` 与 CoPaw token 仅保存在 ECS 环境文件/密钥系统。
- [ ] 定期轮换密钥，失效旧密钥。

## 可观测与恢复

- [ ] Nginx 与应用日志已配置 logrotate。
- [ ] systemd `Restart=always` 生效。
- [ ] 部署后健康检查脚本能返回成功。
- [ ] 已验证回滚脚本可用。
