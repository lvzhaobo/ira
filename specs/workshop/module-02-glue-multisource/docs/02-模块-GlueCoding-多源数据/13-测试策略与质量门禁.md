## 1. 与总表对应

总表 V2 **05b**；对齐 **`05`、`09`、`07`**。

## 2. 测试层级

| 层级 | 覆盖 | P0 最低要求 |
|------|------|-------------|
| **单元** | Provider 适配器（Mock/Wind/Sina）、`stats` 聚合、幂等 key 归一 | 适配器与 job 状态机核心路径覆盖 |
| **集成** | `POST /ingest/jobs` → worker → `ingest_sync_jobs` 终态；可选写 `ingest_feed_items` 或 M1 表 | **≥1** 成功 job + **≥1** 失败 job（模拟上游 503） |
| **契约** | `09` §2 DTO 字段齐全 | 发版前手跑或自动化 |
| **E2E** | 运维页触发同步 → 列表出现成功记录 | US-M2-001 |

### 2.1 用例 ID 示例

| TC-ID | 类型 | 断言 |
|-------|------|------|
| M2-U-JOB-01 | 单元 | `queued` → `running` → `success` 合法转移；非法转移抛错 |
| M2-I-JOB-01 | 集成 | `GET /ingest/jobs/{id}` 与 DB `status` 一致 |
| M2-I-PUB-01 | 集成 | 成功后 `stats.publishedToM1` 与 M1 `research_messages` 增量一致（同库时） |
| M2-I-FAIL-01 | 集成 | 上游失败 → `failed` 或 `partial`，`errorSummary` 非空 |
| M2-E2E-001 | E2E | 触发 Mock 源 → 任务成功 | US-M2-001 |
