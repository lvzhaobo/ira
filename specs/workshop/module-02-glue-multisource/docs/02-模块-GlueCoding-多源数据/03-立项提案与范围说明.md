## 1. 背景与问题

投研资讯来源多、格式不一；需 **可调度、可审计** 的同步管道，并合规使用数据源。

## 2. 提案概要

交付 **ingest** API + 异步作业 + 运维 UI；默认 **Mock** 可演示；真源在合同与密钥就绪后切换配置。

## 3. 范围边界

**范围内**：`09`/`10` P0。  
**范围外**：未授权爬虫；M1 读接口实现；M3 向量流水线。

## 4. 成功标准

- `05` P0 US 可测。  
- 与 M1 对齐的写入字段见 `10` §5。
