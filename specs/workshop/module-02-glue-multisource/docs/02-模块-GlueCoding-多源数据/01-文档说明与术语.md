## 2. 术语与缩写（节选）

| 术语 | 说明 |
|------|------|
| **Glue / 胶水层** | 多源数据采集、清洗、与下游（如 M1/M3）对接的管道与 BFF |
| **Provider** | 外部数据源适配器（Mock / Wind / 新浪等） |
| **SyncJob** | 一次同步任务实例，状态机见 `09` / `10` |
| **BFF** | Backend for Frontend；本模块 REST 入口 |
| **幂等** | 相同触发条件下重复执行不产生重复副作用（见 `09` 与 `Agents.md`） |
