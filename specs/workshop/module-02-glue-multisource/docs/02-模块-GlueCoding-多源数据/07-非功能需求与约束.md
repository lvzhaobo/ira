# 07 — 非功能需求与约束

| 属性 | 内容 |
|------|------|
| **模块编号** | M2 |
| **模块名称** | Glue Coding · 多源数据（Wind / 新浪等） |
| **文档包版本** | v1.2 |
| **技术栈** | 前端 React · 后端 Flask · 代码 GitHub |
| **开发方式** | CoPaw + 本模块 Spec |
| **模块侧重** | 多源行情与资讯的采集、清洗、调度与可观测；强调数据管道与失败降级。 |

---

## 1. 性能与可用性

| 端点 / 能力 | P95 目标 | 说明 |
|-------------|----------|------|
| `GET /ingest/health` | ≤ 200 ms | |
| `GET /ingest/sources` | ≤ 500 ms | |
| `POST /ingest/jobs` | ≤ 500 ms | 仅入队，不含作业完成 |
| 单作业 Wall-clock | 依数据量 | 在 `12` 压测登记；超时标记 `partial`/`failed` |

**并发**：同源 `running` 默认 **1**（可配置）；防止打爆上游。

## 2. 安全与合规

- **密钥**：仅 `secret_ref`；轮换 **≤ 90 天**（Mock 可跳过）。  
- **行情版权**：落地字段须含 `as_of`/`source`（可进 `metadata` 写 M1）。  
- **日志**：不打原始 API Key；`module=M2`。

## 3. 可观测性

- 指标：`m2_jobs_total{status}`、`m2_job_duration_seconds`、`m2_upstream_errors_total`。  
- 告警：连续 **M2_UPSTREAM_UNAVAILABLE** 或 失败率 **> 30%**（15 min）→ P2。

## 4. 阿里云

SLS 采集；大批量 **OSS**；调度可选 **FC** 触发 `POST /ingest/jobs`（服务账号）。
