## 1. 相关方

| 角色 | 关切 |
|------|------|
| **投研 / 业务** | 数据时效、覆盖品种、失败时可解释 |
| **研发** | 可测契约、可观测、可回滚 |
| **合规 / 风控** | 外采数据源授权、日志留存、密钥不落盘 |
| **运维** | 调度可重跑、告警、容量 |

## 2. 模块边界（兄弟模块）

| 方向 | 约定 |
|------|------|
| **→ M1** | 成功路径写入 `research_messages`（或约定主题）；不经 M1 公开 REST 做批量灌数 |
| **→ M3** | 可选：提供清洗后文本片段 / 导出视图（P1） |
| **← CoPaw** | Cron / Skill 触发、MCP 封装数据源；**批处理状态与幂等** 以 BFF + DB 为准 |

## 3. 非目标（本模块不做）

- 替代 **知识库检索与问答** 主链路（属 M3）。  
- 在 Agent 对话循环内实现 **长时同步** 核心逻辑（应用侧作业 + 队列为准）。
