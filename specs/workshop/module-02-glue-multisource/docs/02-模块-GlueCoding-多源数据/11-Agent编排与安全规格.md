# 11 — Agent 编排与安全规格

| 属性 | 内容 |

---

## 1. 定位

本模块 **主链路** 为可审计的 **批处理 / 同步作业**（见 `06`、`08`、`09`）。CoPaw / Agent 仅作为 **触发与编排辅助**，不承载作业状态真源。

## 2. 推荐集成

| 模式 | 说明 |
|------|------|
| **Cron / Skill** | 定时或对话触发 → HTTP 调本模块 BFF（如 `POST /ingest/jobs`） |
| **MCP** | 将「拉取外部源」封装为工具；**结构化结果** 交给 BFF 落库，Agent 不直接写业务库 |
| **人工运维** | React 运维台触发与查看（与 `06` 叙事一致） |

## 3. 安全要求

- **密钥**：仅 `secret_ref` / 环境变量；禁止写入 Spec、日志与仓库。  
- **出站**：外网数据源走白名单与审计；Mock 与生产 **配置分离**。  
- **权限**：触发作业的 Principal（人 / Skill / Cron）需可追踪，与 `jobId` 关联。

## 4. 不宜事项

- 用 **多轮 ReAct** 替代 **幂等、可重跑** 的同步状态机。  
- 在 Agent 上下文中长期持有 **大批量原始资讯**（应落对象存储或库表）。
