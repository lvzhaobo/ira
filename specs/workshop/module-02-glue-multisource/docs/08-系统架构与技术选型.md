## 1. 逻辑架构

- React SPA ↔ Flask API（`BASE=/api/v1`）↔ 本模块领域服务 ↔ 外部依赖（数据源/向量/IM Webhook 等）。  
- 标出与 **兄弟模块** 的边界：向 M1 提供统一消息/资讯写入接口或主题；M3 可选用清洗后的文本片段。

## 2. 技术选型

| 层 | 选型 | 说明 |
|----|------|------|
| 前端 | React | 与全项目一致 |
| 后端 | Flask | Blueprint 按域拆分 |
| 持久化 | PostgreSQL（建议） | RDS |
| 对象 | OSS（若本模块需要） | 存文件/快照 |

## 3. 部署与环境

- `dev` / `staging` / `prod`；配置来自环境变量与 GitHub Secrets。

## 4. CoPaw 边界

见全项目 [`00` §7](../../../00-全项目-企业研发规范-Mock.md)。本模块：**Cron/Skill 触发同步、MCP 封装数据源** 为推荐用法；**批处理状态与幂等** 以 BFF + DB 为准，不放入 Agent 核心循环。

## 5. ira.vin Mock 与 `IRA_VIN_MOCK_BASE`

- 开发/演示用多源 JSON Mock 见仓库 **`samples/ira-vin-mocks`**，规格见同目录 **`SPEC.md`**（路径均以 **`/mock/v1/...`** 为前缀）。  
- **正式对外 Base URL**（是否采用 `https://ira.vin` 等）由部署决定；BFF / 连接器 **勿写死 host**，统一用环境变量 **`IRA_VIN_MOCK_BASE`**（不含尾部 `/`），与 `SPEC.md`、本模块 **`09`** 中示例 URL 保持同一前缀。  
- 域名冻结后：更新 **`09` 示例**与 **`SPEC.md`** 中的 Base 一行即可；路径段不变。
