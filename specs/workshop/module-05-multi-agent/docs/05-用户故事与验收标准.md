> 每条故事 **同一文档内** 写全：**US + AC + REQ**；示例如下，实施时替换为真实编号。

## 示例 US-1（P0）

| 字段 | 内容 |
|------|------|
| **编号** | US-M5-001 |
| **故事** | 作为投研用户，我希望发起标的/议题辩论并拿到可追溯的多视角纪要，以便早会前快速对齐多空分歧（见 `06` §1 三 Agent）。 |
| **AC** | 1) 会话内至少各出现一次 `M5-BULL`、`M5-BEAR` 发言且 `M5-MOD` 产出结构化纪要；2) 主路径 E2E 走通；3) 错误码与 `09` 一致；4) 工具调用带 `agent_id` 审计或等价日志 ID。 |
| **REQ** | REQ-M5-001 → 见 `11` 追踪矩阵 |
