## 1. 背景与问题（基金投研）

多角色 Agent 辩论、工具白名单、纪要导出与合规免责声明。

## 2. 提案概要

在统一「投研助手」应用内交付 **M5** 能力切片，采用 **React + Flask**，代码 **GitHub** 管理，整体用 **CoPaw** 辅助实现；与兄弟模块通过 REST/事件只读契约集成。

**多 Agent 定义**：P0 固定三角色（`M5-BULL` / `M5-BEAR` / `M5-MOD`）+ 编排器；角色职责、工具边界与禁止项以 **`06` §1** 为立项基线，开发前须评审锁定。

## 3. 范围边界

**范围内**：本模块 README 中声明的 MVP 能力。  
**范围外**：全自动下单、保证收益类表述、未授权数据源抓取。

## 4. 成功标准（可度量）

- 本模块 P0 用户故事在 `05` 中全部可测，并在 `11` 中映射到测试层级。
- 与集成方模块联调用例 ≥ 1 条在 `11` 中登记。

## 5. 风险（简表）

| 风险 | 应对 |
|------|------|
| 兄弟模块契约延期 | Mock 接口 + 契约测试 |
| 阿里云配额 | 本地替身 + 降级路径在 `07` 说明 |
