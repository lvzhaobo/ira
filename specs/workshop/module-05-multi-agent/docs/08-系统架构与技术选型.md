## 1. 逻辑架构

- React SPA ↔ Flask API（`BASE=/api/v1`）↔ **编排器（非对话 Agent）** ↔ 多 LLM 实例（`M5-BULL` / `M5-BEAR` / `M5-MOD`，定义见 `06` §1）↔ 白名单工具（M2/M3）。  
- 标出与 **兄弟模块** 的边界：只读调用 M3 检索工具；展示行情工具须与 M2 数据契约一致；会话模型继承全局 Chat。

## 2. 技术选型

| 层 | 选型 | 说明 |
|----|------|------|
| 前端 | React | 与全项目一致 |
| 后端 | Flask | Blueprint 按域拆分 |
| 持久化 | PostgreSQL（建议） | RDS |
| 对象 | OSS（若本模块需要） | 存文件/快照 |

## 3. 部署与环境

- `dev` / `staging` / `prod`；配置来自环境变量与 GitHub Secrets。

## 4. CoPaw 边界

见全项目 [`00` §7](../../00-全项目-企业研发规范-Mock.md)。本模块：**多 Agent** 可选用 CoPaw 协作能力与 **MCP 工具**，或与 **Flask 编排器** 二选一（`11` 冻结）；**`09`/`10` 契约、白名单与审计** 不随集成方式改变。
