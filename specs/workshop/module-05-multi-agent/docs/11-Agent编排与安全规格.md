# 11 — Agent 编排与安全规格

| 属性 | 内容 |

## 1. 定位

M5 强调 **多 Agent 协作** 完成基金投研分析编排；**`09` / `10` 契约、白名单与审计** 为真源，不因选用 CoPaw 或自研编排器而弱化。

## 2. 编排选项（与 `08` §4 一致）

| 选项 | 说明 |
|------|------|
| **CoPaw 多 Agent** | 利用内置协作、Skill、Workflow；工具调用须符合 `09` 暴露的 API |
| **Flask 编排器** | 服务侧状态机 / 有向无环图调度多个「分析步骤」；Agent 可作为一步的实现 |
| **混合** | 编排器调用 CoPaw 完成子任务；**边界与超时** 在 BFF 层统一 |

## 3. 安全

- **工具白名单**：Agent / MCP 仅可调允许列表内 HTTP 与内部函数。  
- **人工介入点**：发布类、对外报送类步骤须 **HITL**（Human-in-the-loop）可配置。  
- **审计**：`trace_id`、调用链与模型版本可回放；敏感参数不入 Prompt 明文。
