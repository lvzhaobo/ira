## 1. 与总表对应

总表 V2 **05b**；对齐 **`05`、`06` §1、`09`、`11`、`07`**。

## 2. 测试层级

| 层级 | 覆盖 | P0 |
|------|------|-----|
| **单元** | 编排状态机（轮次顺序）、工具名白名单校验、非法工具拒绝 | |
| **集成** | `POST /experts/sessions`、`GET`、`POST .../turn`；`debate_tool_calls` 写入；Mock LLM 固定响应 | **≥1** 会话走完 BULL+BEAR+MOD |
| **契约** | `Utterance`、`agentId` 枚举与 `09` §2 一致 | |
| **E2E** | 创建 → 多轮 → 导出 Markdown | US-M5-001（见 `05`） |

### 2.1 用例 ID 示例

| TC-ID | 断言 |
|-------|------|
| M5-U-TOOL-01 | 请求未授权工具 → 拒绝且不写入 `ok` 的 tool_call |
| M5-I-SESS-01 | 创建会话字段与 `09` §3.2 一致 |
| M5-I-TURN-01 | `newUtterances` 中 `agentId` ∈ {`M5-BULL`,`M5-BEAR`,`M5-MOD`} |
| M5-I-MOD-01 | 终态含 `M5-MOD` 发言且 `structured` 或正文含免责声明区块（与 `06` 约定） |
| M5-I-EXP-01 | `GET .../export?format=markdown` 非空且含免责声明 |
| M5-E2E-001 | 浏览器完整辩论 + 导出 | US-M5-001 |

## 3. 质量门禁（加强项）

| 门禁 | 说明 | 阻塞 |
|------|------|------|
| G-M5-LINT | 常规 | 是 |
| G-M5-UNIT+INT | M5-U-TOOL-01、M5-I-TURN-01、M5-I-MOD-01 绿 | 是 |
| G-M5-GOLDEN | **黄金用例集**（固定 prompt + Mock）输出与快照比对（允许白名单字段漂移） | 是（发版） |
| G-M5-SAST | 依赖扫描；**无** 硬编码生产密钥 | 是 |

LLM 与 M2/M3 工具 **默认 Mock**；联调真实服务用 **单独 job** 或 nightly，避免 PR 不稳定。
