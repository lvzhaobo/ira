## 2. 里程碑（M0～M4）

**说明**：下表是**阶段验收节点**（到什么状态算「这一阶段过了」），粒度是**里程碑**，不是可直接估人天的任务单。**可拆工作包**见 §3，可按迭代把 §3 条目勾选进 Sprint。

| 阶段 | 交付要点 |
|------|-----------|
| **M0** 基线 | 工具白名单、免责声明与提示词评审通过（`06`/`11` 冻结一版） |
| **M1** 最小闭环 | `M5-BULL` + `M5-BEAR` 首轮可跑通 + 会话/发言落库（`10`）+ `09` 创建会话与单次 `turn` + 基础审计日志 |
| **M2** 产品化 | 多轮编排、`M5-MOD` 纪要、工具调用入库（`debate_tool_calls`）、纪要导出（`09` MD，PDF 可选） |
| **M3** 质量门禁 | 黄金用例集（对齐 `05` US-1 AC）、安全扫描、白名单外工具调用必失败（`13` 与 `11` 一致） |
| **M4** 生产就绪 | 模型路由/限流/配额、可观测性达标（`07`）、与 M3 检索 + M2 只读行情联调冻结 |

## 3. 任务拆分（WBS，可派工）

按角色标注 **BE** 后端 / **FE** 前端 / **DO** 文档与配置 / **QA** 测试；顺序为建议依赖顺序，可部分并行。

## 4. 任务与依赖（摘要）

- **硬依赖**：M0（白名单/提示词）→ M1（API+库）→ M2（工具与导出）→ M3（测）→ M4（产线）。  
- **可并行**：M1 中 FE 可在 M1-T2 Mock 契约后并行；M2-T6 可与 M2-T5 并行。  
- **跨模块**：M3 检索、M2 行情以只读契约为准，延期则用 Mock + 契约测试（`03` 风险表）。

## 5. 风险与应对

模型幻觉 → 强制引用与人工复核；工具越权 → 白名单+审计。
